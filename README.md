# Rue Abando — Portfolio

Personal portfolio site (HTML + CSS).

## Local preview

Open `index.html` in your browser, or use a simple local server:

```bash
npx serve .
```

Profile photo lives at `assets/photo.jpg` and is used in the hero, about, contact, and site icon.

## Deploy

See [GitHub Pages](#github-pages-recommended) below, or host on Netlify / Vercel by connecting this repository.
